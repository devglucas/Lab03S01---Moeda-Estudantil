## Histórias do Usuário

### HU01, Realizar Login
Como professor/aluno, eu quero ter a possibilidade de realizar login, para ter acesso as funcionalidades do site.

### HU02, Cadastrar-se
Como aluno, eu quero conseguir me cadastrar na plataforma, para ter acesso as funcionalidades

### HU03, Enviar moedas a um aluno
Como professor, quero conseguir enviar moedas a um aluno, junto aos motivos para o envio. Para dar ao aluno um ganho pelos seus estudos.

### HU04, Consultar Extrato
Como professor, quero conseguir consultar o historico de moedas enviadas aos alunos, para controle pessoal e conferir.

### HU05, Trocar moedas por vantagem
Como aluno, quero conseguir realizar a troca das minhas moedas por beneficios. Para gastar as moedas e ter os ganhos

### HU06, Cadastrar vantagem
Como professor quero conseguir realizar o cadastro de beneficios e vantagem para os alunos trocarem por moedas

### HU07, Conferir troca de vantagem
Como professor quero ter um acesso facilitado para conferir as trocas realizadas por alunos, para validar se ocorreu tudo com esperado

### HU08, Enviar notificação via email
Como professor, quero receber email quando receber novas moedas a serem distribuidas, para lembrete. E quando alunos fizerem resgates de beneficios ou vatagens 
Como aluno, quero receber email quando quando receber moedas pelo professor ou quando novos beneficios e vantagens forem cadastrados

### HU09, Enviar notificação via email
Como aluno, quando receber novas moedas quero receber meu cupom via email, para realizar a troca do cupom
